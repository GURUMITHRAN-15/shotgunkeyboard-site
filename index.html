What it does

A firing range under your fingers

Sound settings

Works in every program

A global keyboard hook listens in Notepad, your browser, your editor and your chat apps. It keeps working while the window is hidden in the tray.

Sounds stack

Up to 16 sounds can play at once, and you can raise that to 32. Past the limit the oldest one fades out in a few milliseconds, so you never hear a click.

Built for typing

A held key fires once, unless you turn on retrigger in the Sound settings. Every key plays the same punchy shotgun blast.

Every sound is generated

The app builds the sound from maths: a sharp crack, a low punch, a burst of noise and a short tail. There are no recordings and no sample packs.

Run from the tray

Arm and disarm from the tray icon or with Ctrl+Alt+Shift+K. The app always starts disarmed, so it never surprises you at login.

Private

It plays a sound when a key goes down. It does not record, save or send what you type. It never connects to the internet and has no account or telemetry.

Yours to tune

Volume, intensity, pitch, duration and the voice limit are sliders. Start with Windows and Launch minimized are one click each.

Questions

Before you download

Does it record what I type?

No. The app only needs to know that a key went down so it can play a sound. It does not store, log or send keys, characters or passwords, and it never connects to the internet.

Which computers does it run on?

It is built for Windows 10 and 11, 64-bit. There is no Mac or Linux version.

Windows says "Windows protected your PC". Is that normal?

Yes. The app is not code-signed, so SmartScreen shows that warning for new programs. Choose More info, then Run anyway. Some antivirus tools also flag any program that listens to the keyboard. If yours does, add an exception for the file.

Will it work in programs that run as Administrator?

Windows only passes those key presses to programs that also run as Administrator. The app has a Restart as Administrator button for this, and it only asks when you click it.

What about online games?

Some anti-cheat systems dislike programs that listen to the keyboard. Disarm or quit ShotgunKeyboard before you start a game that uses one.

Can it get too loud?

Every sound is peak-limited and the app has a volume slider. It also starts disarmed, so nothing plays until you arm it.
